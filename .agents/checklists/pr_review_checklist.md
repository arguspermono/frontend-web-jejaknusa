# PR Review Checklist

Before merging into `develop` or `main`:

- [ ] Does the UI match the Figma design (spacing, fonts, colors)?
- [ ] Is it responsive across Mobile, Tablet, and Desktop breakpoints?
- [ ] Are Tailwind classes ordered cleanly?
- [ ] Did you test Dark/Light mode if applicable?
- [ ] Are semantic HTML tags used?
- [ ] Are all new images optimized and provided with `alt` attributes?
- [ ] Have all unused files or console logs been removed?
- [ ] Does `npm run build` succeed without errors?
