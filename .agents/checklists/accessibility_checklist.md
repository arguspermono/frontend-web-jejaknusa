# Accessibility (a11y) Checklist

- [ ] Ensure `<html>` has `lang="en"`.
- [ ] Check contrast ratio for text (especially in Dark/Light modes).
- [ ] Ensure all `<input>`, `<textarea>`, and `<select>` have associated `<label>` tags.
- [ ] Add `aria-label` to interactive elements without text (e.g., hamburger menu `<button>`).
- [ ] Provide `alt` text for all non-decorative `<img>` tags.
- [ ] Ensure logical heading hierarchy (H1 -> H2 -> H3) with no skipped levels.
- [ ] Test keyboard navigation (Tab through the page, check focus rings).
