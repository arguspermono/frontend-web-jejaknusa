# Architecture: Component Map

Even in vanilla HTML, we treat UI elements as components.

- **Navbar:** Sticky header, responsive hamburger, theme toggle.
- **Footer:** Links, social icons, newsletter signup (UI only).
- **Hero:** Home page banner with CTA.
- **DestinationCard:** Reusable HTML snippet for list items. Includes image, title, location, and rating.
- **ArticleCard:** Snippet for user experiences. Includes user avatar, snippet, image, and read more link.
- **SearchForm:** Form for filtering destinations.
- **ContactForm:** Basic form with name, email, message.
